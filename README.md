# Data Analytics Projects

Two applied data analysis projects: predicting customer churn for a telecom provider, and identifying the economic drivers of county-level poverty using U.S. Census data.

## Projects

- [`customer-churn-prediction/`](./customer-churn-prediction) — Compared three classification models (Logistic Regression, Decision Tree, Naive Bayes) to predict telecom customer churn and identify the strongest churn drivers.
- [`county-poverty-prediction/`](./county-poverty-prediction) — Multiple linear regression identifying which economic and employment factors most strongly predict poverty rate across 3,220 U.S. counties.

Each project folder has its own README with the research question, method, code, and results.
